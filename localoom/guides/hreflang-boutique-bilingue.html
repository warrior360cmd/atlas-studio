Hreflang pour une boutique bilingue français-anglais

À quoi servent les balises hreflang sur une boutique en ligne bilingue, comment les déclarer, et les erreurs qui empêchent les moteurs de les prendre en compte.

Les balises hreflang indiquent aux moteurs de recherche qu’une page existe en plusieurs langues et quelle version montrer à quel public. Sans elles, une boutique bilingue risque de voir la mauvaise version affichée, ou les deux versions se faire concurrence.

Le principe

Chaque page déclare toutes ses versions linguistiques, y compris elle-même. La page produit française indique sa version anglaise, et la page anglaise indique sa version française. Une valeur « x-default » peut désigner la version à montrer par défaut.

Les conditions pour qu’elles fonctionnent

  1. Réciprocité : si la page A désigne la page B, la page B doit désigner la page A.
  2. Adresses complètes et canoniques : chaque version a sa propre adresse, accessible et non redirigée.
  3. Codes corrects : « fr », « en », ou plus précis comme « en-GB » ou « en-US » si vous ciblez un pays.
  4. Cohérence avec la balise canonique : chaque version doit être canonique pour elle-même, pas pointer vers l’autre langue.

Où les déclarer

Dans l’en-tête HTML de chaque page, dans les en-têtes HTTP ou dans le sitemap. Beaucoup de plateformes et d’extensions multilingues les génèrent : vérifiez le résultat dans le code source d’une page.

Les erreurs fréquentes

  • Une version qui pointe vers une page inexistante ou redirigée.
  • Des balises présentes sur l’accueil mais pas sur les fiches produits.
  • Un code de langue inventé.
  • Des pages anglaises qui contiennent encore du texte français.

Le lien avec la traduction

Les balises ne servent à rien si la page anglaise est incomplète. Une traduction complète et contrôlée reste la base ; voir traduire ses fiches produits et SEO d’une fiche produit.
