Title et meta description d’une page produit

Rédiger le title et la meta description d’une page produit : longueur indicative, mots-clés, informations utiles et adaptation dans chaque langue.

Le title et la meta description sont souvent ce que le client voit en premier dans les résultats de recherche. Ils ne garantissent pas un classement, mais ils influencent le choix de cliquer.

Le title

Le title est le titre de la page affiché dans l’onglet et, souvent, dans les résultats de recherche. Bonnes pratiques :

  • Commencer par le type de produit et sa caractéristique principale.
  • Ajouter une précision utile (matière, taille, usage).
  • Terminer, si la place le permet, par le nom de la boutique.
  • Rester assez court pour ne pas être coupé, autour de 50 à 60 caractères à titre indicatif.

Exemple : « Bol en grès émaillé 15 cm, vert sauge | Atelier Dupont ».

La meta description

Elle résume la page en une ou deux phrases. Les moteurs ne l’affichent pas toujours, mais une description claire aide quand elle est reprise. Visez environ 120 à 160 caractères, avec les informations qui aident à choisir : matière, dimension, usage, avantage concret.

Éviter les doublons

Chaque produit doit avoir son propre title et sa propre description. Des pages aux titres identiques sont difficiles à distinguer pour les moteurs comme pour les clients.

Dans chaque langue

Rédigez le title et la description directement dans chaque langue, avec les mots que les clients de ce marché utilisent. Une traduction littérale d’un title français n’est pas toujours la formulation recherchée en anglais.

Rester honnête

Le title et la description doivent correspondre au contenu de la page. Promettre une promotion ou une caractéristique absente déçoit le visiteur. Voir aussi SEO d’une fiche produit.
