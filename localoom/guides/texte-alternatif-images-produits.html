Texte alternatif des images produits : bien l’écrire

Écrire un texte alternatif utile pour les images de produits : accessibilité, description concrète, longueur, langue et erreurs fréquentes à éviter.

Le texte alternatif (attribut alt) décrit une image pour les personnes qui ne la voient pas : utilisateurs de lecteurs d’écran, connexions lentes, moteurs de recherche. Pour une boutique, c’est à la fois une question d’accessibilité et de référencement.

Décrire ce que montre l’image

Le texte alternatif doit dire ce que l’on voit : le produit, sa couleur, l’angle ou le détail montré. « Bol en grès vert sauge vu de dessus, intérieur émaillé brillant » est utile. « Image produit 1 » ne l’est pas.

Rester concis

Une phrase suffit en général. Inutile de commencer par « image de » : les lecteurs d’écran annoncent déjà qu’il s’agit d’une image.

Différencier les images

Une fiche contient souvent plusieurs photos. Chaque texte alternatif décrit ce qui est propre à l’image : vue de face, détail de la couture, produit en situation, étiquette de composition.

Éviter le bourrage

Répéter des mots-clés dans le texte alternatif n’aide pas et nuit à l’accessibilité. Écrivez pour une personne, pas pour un moteur.

Les images décoratives

Une image purement décorative, sans information, peut avoir un texte alternatif vide (alt=""), pour que les lecteurs d’écran l’ignorent.

Dans chaque langue

Le texte alternatif doit être traduit comme le reste de la fiche. C’est un oubli fréquent : la boutique anglaise affiche alors des descriptions d’images en français. Incluez ce champ dans le fichier de traduction et dans le contrôle qualité.

Le nom du fichier

Un nom de fichier descriptif (bol-gres-vert-sauge.jpg) est plus clair qu’un nom généré par l’appareil photo. Voir aussi SEO d’une fiche produit.
