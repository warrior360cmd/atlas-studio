Construire un glossaire pour traduire un catalogue

Pourquoi et comment construire un glossaire de traduction pour un catalogue e-commerce : termes de métier, noms à ne pas traduire, variantes et décisions de style.

Un glossaire est la liste des décisions de traduction prises une fois pour toutes. Il garantit qu’un même terme est traduit de la même façon sur tout le catalogue, quel que soit le traducteur ou l’outil.

Ce qu’il contient

  • Les termes de métier : matières, finitions, techniques de fabrication.
  • Les noms à ne pas traduire : marques, noms de collections, noms de produits déposés.
  • Les termes récurrents de l’interface et des fiches : « livraison offerte », « fait main ».
  • Les choix de style : variante d’anglais, majuscules dans les titres, unités.

Exemples de termes de métier

Certains mots ont une traduction précise qu’un outil générique ne choisit pas toujours :

  • faïence : earthenware
  • grès : stoneware
  • porcelaine : porcelain
  • lin : linen
  • laine mérinos : merino wool
  • cuir pleine fleur : full-grain leather
  • acier inoxydable : stainless steel
  • bois massif : solid wood

Vérifiez toujours le terme dans le contexte de votre produit et de votre secteur.

Comment le construire

  1. Relevez les termes qui reviennent le plus dans le catalogue.
  2. Décidez leur traduction avec quelqu’un qui connaît le métier.
  3. Notez un exemple d’usage pour chaque terme.
  4. Partagez le glossaire avec toute personne qui traduit ou relit.

Le faire vivre

Ajoutez les nouveaux termes au fil des collections. Quand une décision change, mettez à jour les fiches concernées pour rester cohérent.

L’utiliser dans le contrôle

Un glossaire permet un contrôle automatique simple : vérifier qu’un terme source est bien rendu par la traduction convenue. Voir contrôle qualité et vocabulaire des matières.
