Importer des produits dans Shopify par fichier CSV

Préparer un fichier CSV d’import Shopify : colonnes principales, handle, variantes, images et traductions, et les erreurs à éviter avant de tout importer.

Shopify permet d’importer et d’exporter des produits au format CSV. C’est la méthode la plus sûre pour mettre à jour un grand nombre de fiches, à condition de respecter le modèle attendu.

Partir d’un export

Le plus fiable est d’exporter d’abord vos produits depuis l’administration Shopify. Vous obtenez un fichier avec les bonnes colonnes et les identifiants existants. Modifier ce fichier évite les erreurs de structure.

Les colonnes clés

Le modèle de Shopify comprend notamment un identifiant de produit (Handle), le titre, la description en HTML, le fournisseur, le type, les étiquettes, les options et valeurs de variantes, le SKU, le prix et les images. Consultez la documentation officielle de Shopify pour la liste à jour : le modèle évolue.

Le handle

Le handle identifie le produit. Les lignes qui partagent le même handle décrivent les variantes ou les images d’un même produit. Si vous changez un handle, Shopify créera un nouveau produit au lieu de mettre à jour l’existant.

Les traductions

Le CSV produits sert à la langue principale de la boutique. Les traductions sont gérées par les fonctions de langues de Shopify et par les applications de traduction, qui ont souvent leur propre format d’import et d’export. Vérifiez lequel vous utilisez avant de préparer le fichier anglais.

Bonnes pratiques

  1. Encodage UTF-8 pour conserver les accents.
  2. Testez l’import sur deux ou trois produits.
  3. Gardez une copie de l’export d’origine.
  4. Vérifiez les variantes et les prix après import.

Contrôler avant d’importer

Un contrôle automatique peut vérifier que chaque SKU existe dans la source et que les nombres sont identiques entre les langues. Voir contrôle qualité et, pour d’autres plateformes, WooCommerce et PrestaShop.
