Sources publiques pour qualifier une entreprise en France

Annuaire des Entreprises, registre national, BODACC, site carrière : les sources publiques pour qualifier une entreprise française et ce que chacune apporte.

Avant d’acheter une base de données, il est utile de savoir ce que les sources publiques permettent déjà de vérifier. En France, une grande partie des informations légales sur une entreprise est accessible gratuitement.

Les registres officiels

  • Annuaire des Entreprises (annuaire-entreprises.data.gouv.fr) : service public qui rassemble l’identité légale, le SIREN, les établissements, l’activité déclarée (code NAF) et les dirigeants déclarés.
  • Répertoire SIRENE de l’Insee : la base d’identification des entreprises et de leurs établissements, également disponible en données ouvertes.
  • Registre national des entreprises (INPI) : formalités, actes et, quand ils sont publiés, comptes annuels.
  • BODACC : annonces légales commerciales, par exemple créations, ventes, modifications, procédures collectives.

Ces sources disent qui est l’entreprise. Elles disent rarement ce qu’elle cherche à faire.

Les sources d’intention

  • Le site de l’entreprise : offres, pages produits, actualités, clients cités.
  • Le site carrière et les offres d’emploi : ce sont souvent les indices les plus précis sur les projets en cours.
  • Les communiqués et rapports annuels pour les entreprises qui en publient.
  • La presse spécialisée du secteur.

Bonnes pratiques

  1. Citez l’adresse exacte de la page consultée, pas seulement le nom du site.
  2. Notez la date de consultation.
  3. Distinguez ce que la source affirme de ce que vous en déduisez.
  4. Ne recopiez pas de données personnelles qui ne servent pas votre démarche ; voir prospection B2B et RGPD.

Limites

Le code NAF reflète l’activité déclarée, pas toujours l’activité réelle. Les effectifs publiés sont des tranches, parfois anciennes. Les comptes peuvent être déposés avec une option de confidentialité. Pour ces raisons, un fait important doit être confirmé par une deuxième source, comme expliqué dans vérifier et dater les données.
