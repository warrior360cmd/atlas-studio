Factur-X expliqué simplement : un PDF qui contient ses données

Ce qu’est une facture Factur-X, comment elle combine un PDF lisible et un fichier XML structuré, et pourquoi c’est un format admis par la réforme.

Factur-X est un format de facture hybride : un PDF que tout le monde peut lire, dans lequel est intégré un fichier XML contenant les données de la facture de façon structurée.

Deux lectures d’un même document

  • Une personne ouvre le PDF comme une facture ordinaire.
  • Un logiciel lit le fichier XML intégré : numéro, dates, vendeur, client, lignes, montants, TVA.

Les deux doivent dire la même chose. Un écart entre le PDF et le XML est une source d’erreurs à éviter.

Pourquoi c’est utile

Le format évite la ressaisie : la comptabilité du client peut intégrer la facture automatiquement. C’est aussi l’un des trois formats du socle retenu par la réforme française, avec UBL et CII : voir les trois formats.

Le fichier XML

Il suit la syntaxe CII (Cross Industry Invoice) et un profil qui fixe le niveau de détail. Tous les profils ne se valent pas : voir les profils Factur-X.

Comment savoir si une facture est un Factur-X

Un PDF ordinaire n’a pas de fichier XML intégré. Notre outil gratuit ouvre le PDF dans votre navigateur, cherche le XML et le contrôle, sans rien envoyer sur un serveur.

À retenir

Factur-X ne dispense pas des autres obligations : la facture doit passer par une plateforme agréée et contenir toutes les mentions légales. Voir les mentions obligatoires.
