Extraire des données de factures PDF de façon fiable

Extraire montants, dates et numéros de factures PDF : PDF texte ou scanné, OCR, contrôles de cohérence et validation humaine des cas incertains.

Beaucoup de documents administratifs arrivent en PDF. En extraire automatiquement les données (montants, dates, numéros) est possible, mais la fiabilité dépend du type de PDF et des contrôles mis en place.

Deux types de PDF

  • PDF texte : généré par un logiciel, le texte est sélectionnable. L’extraction est en général fiable, surtout si la mise en page est toujours la même.
  • PDF scanné : c’est une image. Il faut une reconnaissance de caractères (OCR), plus sujette aux erreurs.

Les approches

  1. Modèles par fournisseur : on décrit où se trouve chaque information pour une mise en page donnée. Fiable, mais à maintenir.
  2. Outils d’extraction généralistes et modèles d’IA : plus souples, mais leurs résultats doivent être vérifiés.
  3. Données structurées : certaines factures électroniques contiennent les données sous forme lisible par machine ; c’est la meilleure source quand elle existe.

Les contrôles indispensables

  • Le total hors taxes plus la TVA égale le total TTC.
  • La date est plausible (ni dans le futur, ni très ancienne).
  • Le numéro de facture n’a pas déjà été traité (doublon).
  • Le fournisseur est connu.

Une donnée qui échoue à un contrôle va dans la file d’exceptions, jamais directement en comptabilité.

Ne jamais inventer

Si un montant n’est pas lisible, l’automatisation doit le signaler, pas le deviner. C’est particulièrement vrai avec les modèles d’IA, qui peuvent produire une valeur plausible mais fausse.

Garder le lien avec le document

Chaque donnée extraite doit rester liée au PDF d’origine pour permettre la vérification. Voir aussi traitement des factures fournisseurs.
