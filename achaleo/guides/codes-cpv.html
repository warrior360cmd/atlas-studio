Codes CPV : bien les choisir pour ne rater aucun marché

Les codes CPV classent chaque achat public. Comment trouver ceux de votre métier, pourquoi en suivre plusieurs et les erreurs qui font manquer des marchés.

Le CPV (Common Procurement Vocabulary, vocabulaire commun pour les marchés publics) est une nomenclature européenne. Chaque avis de marché indique un code principal et parfois des codes secondaires. C’est le filtre le plus fiable d’une veille.

Comment ils sont construits

Un code CPV compte huit chiffres suivis d’un chiffre de contrôle. Les premiers chiffres désignent une famille large, les suivants précisent. Par exemple, une famille regroupe les travaux de construction, une sous-famille les travaux de toiture. Plus la partie significative du code est courte, plus il est large.

Trouver les vôtres

  1. Partez de ce que vous vendez réellement, pas de l’intitulé de votre activité.
  2. Cherchez dans la nomenclature officielle les codes qui décrivent ces prestations.
  3. Regardez les avis d’attribution de marchés que vous auriez pu gagner : notez les codes utilisés par les acheteurs.
  4. Gardez le code de famille en plus des codes précis.

Les erreurs fréquentes

  • Un seul code : les acheteurs classent un même besoin de façons différentes. Un nettoyage de locaux peut apparaître sous un code de services de nettoyage ou sous un code plus général de services aux bâtiments.
  • Ignorer les codes secondaires : un marché multi-lots porte souvent le code de son lot principal ; votre lot est peut-être en secondaire.
  • Ne jamais réviser : après un mois, regardez ce que la veille a manqué et ajustez.

À retenir

Les mots-clés rattrapent ce que les codes manquent, et inversement : une bonne veille combine les deux. Voir trouver des appels d’offres sur le BOAMP.

Sources officielles
