Définir son profil de client idéal (ICP) en B2B

Comment définir un profil de client idéal exploitable : critères vérifiables, critères d’exclusion et lien avec vos meilleurs clients actuels, sans jargon.

Le profil de client idéal, souvent appelé ICP (ideal customer profile), décrit le type d’entreprise pour lequel votre offre a le plus de valeur. Il ne décrit pas une personne mais une organisation. Bien écrit, il sert de filtre à toute la recherche commerciale.

Partir de vos clients réels

Listez les clients avec lesquels la collaboration se passe bien : ils paient, restent, recommandent. Cherchez ce qu’ils ont en commun de façon observable : secteur, nombre de sites, outil utilisé, mode de vente, zone géographique. Méfiez-vous des points communs qui ne se vérifient pas de l’extérieur, comme « culture d’innovation ».

Séparer critères obligatoires et critères de priorité

  • Obligatoires : sans eux, l’offre ne s’applique pas (par exemple vendre en ligne pour un service de catalogue).
  • Prioritaires : ils augmentent la probabilité d’intérêt (par exemple un recrutement récent dans le service concerné).
  • Exclusions : les cas où vous refusez de travailler, même si l’entreprise semble correspondre.

Rendre chaque critère vérifiable

Pour chaque critère, notez où l’on peut le constater : registre, site web, offre d’emploi, rapport annuel. Un critère que personne ne peut vérifier finira interprété différemment par chaque commercial.

Tester le profil sur un petit échantillon

Appliquez le profil à une vingtaine d’entreprises trouvées au hasard dans votre secteur. Si presque toutes passent le filtre, il est trop large. Si aucune ne passe, il est trop strict ou repose sur des informations introuvables.

Le relier aux signaux

Un bon profil dit quelles entreprises viser. Les signaux d’achat disent quand les contacter. Les deux ensemble forment la base d’une liste de prospects qualifiée.

Le réviser

Revoyez le profil à chaque trimestre avec l’équipe commerciale : quels critères ont réellement prédit une vente, lesquels n’ont rien changé. Un profil qui ne bouge jamais est souvent un profil que personne n’utilise.
